# 🦷 ДЕНТИКА — Сайт стоматологической клиники

Современный адаптивный сайт-визитка для стоматологической клиники.
Готов к использованию, легко настраивается через CMS-админку.

---

## 🎯 Для кого подходит

- Частные стоматологические клиники
- Стоматологические кабинеты
- Сети клиник
- Врачи, ведущие частную практику

---

## ✨ Возможности

### Дизайн (11 секций)
1. **Шапка** — логотип, меню, телефон, бургер-меню
2. **Hero** — главный экран с призывом и статистикой
3. **Преимущества** — 4 кликабельные плитки
4. **Услуги** — 6 карточек с ценами
5. **Цены** — таблица из 10 позиций
6. **О клинике** — фото + текст + гарантии
7. **Врачи** — 3 карточки специалистов
8. **Галерея** — 4 фото интерьера с лайтбоксом
9. **Отзывы** — 3 отзыва пациентов
10. **Контакты** — 3 равные колонки (инфо + форма + карта)
11. **Подвал** — копирайт и лицензия

### Функционал
- ✅ Адаптив под все устройства (5 брейкпоинтов)
- ✅ Лайтбокс для галереи (стрелки, свайпы, Escape)
- ✅ Cookie-баннер с сохранением выбора
- ✅ Плавающая панель «Позвонить / Записаться» на мобильном
- ✅ Маска телефона +7 (___) ___-__-__
- ✅ Форма отправки через Formspree
- ✅ SEO-метатеги (Open Graph, Twitter Card, geo)
- ✅ Яндекс.Карта в секции контактов
- ✅ Политика обработки ПД (отдельный файл)

## 🚀 Быстрый старт

### Вариант 1: Просто открыть
1. Скачай папку проекта
2. Открой `index.html` в браузере
3. Готово! 🎉

### Вариант 2: Залить на GitHub Pages
1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Settings → Pages → Branch: `main`
4. Через 1-2 минуты сайт доступен по ссылке

## 🎨 Настройка

### Через админку (admin/)
- Тексты всех секций (146 меток `data-edit`)
- Фотографии (9 меток `data-img`)
- Телефоны, адреса, цены, имена врачей

### Вручную (в коде)
- Цветовая схема: поиск по `#0e7490`
- Formspree ID: строка `xvkkbvpd`
- Координаты карты: блок Яндекс.Карт
